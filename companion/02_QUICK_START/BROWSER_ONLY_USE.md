# Browser-only use

The companion can be used without Git, a terminal or a desktop Git client. Open the repository page, select **Code → Download ZIP**, extract the archive and work on copies of the templates outside the extracted reference folder.

Do not edit the only copy. Create a project-specific workspace, preserve the original template filename in a source note and record the companion version and access date. Uploading completed student records back to a public fork is prohibited when they contain personal, confidential or restricted material.
