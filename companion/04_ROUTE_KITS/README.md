# Route kits

This folder expands the four routes that do not have longitudinal named cases in the printed manuscript:

1. algorithmic or simulation study;
2. qualitative inquiry;
3. case study;
4. hybrid route.

Each subfolder contains eight completed CSV records. `ROUTE_WORKED_EXAMPLES_v1.1.1.docx` provides a printable integrated view.

All examples are synthetic or composite. They are designed to demonstrate evidence obligations and claim boundaries, not to supply findings that can be cited or reused.
