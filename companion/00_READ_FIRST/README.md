## Purpose

This package supplies editable, versioned records for the book’s evidence-to-defence chain. It separates a low-friction minimum layer from a fuller audit layer, then provides four synthetic worked examples for routes that are less extensively illustrated in the printed manuscript.

## Start here

1. Open `01_WORKBOOK/COMPANION_WORKBOOK_v1.1.1.docx`.
2. Select the minimum record for the current gate.
3. Move to the full record only when project risk or review burden requires it.
4. Use the CSV with the same name for machine-readable work.
5. Recheck the dated institutional and tool registries before consequential use.
6. Preserve version, date, reviewer, evidence and disposition. Never overwrite a superseded record silently.

## Directory map

- `00_READ_FIRST/` - status, rights, maintenance and limitations.
- `01_WORKBOOK/` - printable and supervisor-facing workbook.
- `02_TEMPLATES_MINIMUM/` - 12 low-friction CSV records.
- `03_TEMPLATES_FULL/` - 33 full CSV records.
- `04_ROUTE_KITS/` - four synthetic route kits and a worked-examples DOCX.
- `05_REGISTRIES/` - institutional, tool, terminology, route, gate and record registries.
- `06_MAINTENANCE/` - changelog, release and supersession controls.
- Historical archived resources and v1.0.0 provenance are intentionally excluded from this repository candidate and retained only in the private handover.

## Non-negotiable boundaries

- Current regulations, programme instructions, official forms and named authorities prevail.
- Gate labels, TRACE, SCOPE, CORPUS and DECIDE are authorial pedagogical controls.
- AI output is candidate work, not evidence or authority.
- No public GitHub release, Zenodo record, DOI or licence is confirmed.
- Do not publish the manuscript, route evidence or figures before rights and privacy are closed.
