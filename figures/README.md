# Student’s Guide figure authority v4.3

The 18 author-corrected ODG files in `01_ODG_NATIVE_EDITABLE/` are the native, object-level editable figure authority. Each controlled individual ODG file is byte-identical to its accepted author-supplied source; the original source filenames and hashes are retained in `06_SOURCE_AND_PROVENANCE/` without duplicating the source files in the public package.

- `01_ODG_NATIVE_EDITABLE/` contains 18 controlled native-authority files and one consolidated 18-page ODG.
- `02_SVG_PUBLICATION_VECTOR/` contains 18 publication-vector derivatives.
- `03_PPTX_NATIVE_EDITABLE/` contains 18 individual editable derivatives and one consolidated deck.
- `04_PNG_600PPI_FALLBACK/` contains 18 technical fallbacks.
- `05_QA/` records structural, visual, accessibility and editability checks and includes one contact sheet.
- `06_SOURCE_AND_PROVENANCE/` records source hashes, byte identity and reproducibility scripts.
