# Editable figures

These 18 figure sets belong to the private repository candidate for **The Informatics Student’s Guide to Research Projects, Theses and Dissertations**.

Subtitle: *From Topic Selection to Evidence, Implementation, Writing and Defence*

## Format authority

1. `01_SVG_AUTHORITATIVE/` contains the canonical vector sources used by the book.
2. `02_PNG_TECHNICAL_FALLBACK/` contains technical fallbacks and previews.
3. `06_ODG_NATIVE_EDITABLE_INDIVIDUAL/` contains 18 LibreOffice Draw files with native, separately editable text, boxes, lines, colours, curves and arrowheads.
4. `07_ODG_NATIVE_EDITABLE_CONSOLIDATED/` contains all figures in one 18-page ODG.
5. `08_PPTX_NATIVE_EDITABLE_INDIVIDUAL/` contains 18 PowerPoint files built from native editable shapes.
6. `09_PPTX_NATIVE_EDITABLE_CONSOLIDATED/` contains all figures in one 18-slide PPTX.
7. `10_NATIVE_EDITABILITY_QA/` records object counts, text round-trip tests, edit-persistence checks and visual comparison evidence.

The native ODG and PPTX files contain no embedded SVG/PNG picture object as the figure body. They are editable derivatives, not a replacement authority. Any accepted edit must be reconciled with the canonical SVG and regenerated or rechecked across all formats.

Public release, licence, DOI and publisher permissions remain on hold. Object-level editability is not a public reuse grant.
