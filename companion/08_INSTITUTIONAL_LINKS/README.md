# Institutional and milestone modules

This directory contains DC-A, DC-B and DC-C, together with the dated source concordance and operational CSV records migrated from the current book appendices. The material is a control aid, not an official institutional form.

Before use, verify route, session, candidate status, source revision and any written clarification. Mark unresolved discrepancies as `CONFLICT` and pause the affected action.

## Phase 14C controls

- `CURRENT_SOURCE_VERIFICATION_LOG_2026-08-23.csv` records the check performed and its limits;
- `CURRENT_SOURCE_CONFLICT_REGISTER_2026-08-23.csv` preserves unresolved source-set disagreements without selecting a value;
- `CURRENT_SESSION_EXCEPTION_REGISTER_2026-08-23.csv` separates mobility-only August announcements from the ordinary route;
- `SOURCE_VERIFICATION_METHOD_AND_LIMITS.md` defines what identity verification does and does not establish.
