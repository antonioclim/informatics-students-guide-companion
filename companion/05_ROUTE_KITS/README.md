# Route kits

The eight route kits translate the common gate architecture into route-specific evidence obligations. They do not create eight separate methodologies and do not replace supervisor approval, ethics, data-owner, security, licence or institutional authority.

Each kit contains:

- a route profile and inference boundary;
- a nine-gate evidence plan;
- a record-selection map pointing to the shared templates;
- a risk and boundary register;
- a synthetic worked example whose files match the exact schema of the referenced templates.

Use one dominant route. Name a secondary component only when it produces distinct evidence. A hybrid route is justified only by an explicit integration product. The worked examples are synthetic teaching objects and are not empirical findings.
