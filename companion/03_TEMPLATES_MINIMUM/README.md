# Minimum templates

Use one minimum template to support the current decision with the least defensible documentation burden. A minimum record is not an exemption from evidence, authority, ethics, rights, privacy, disclosure or version control.

- Preserve the header and UTF-8 encoding.
- Work on a dated copy outside the reference repository.
- Use stable identifiers and ISO dates.
- Do not enter credentials, direct identifiers, restricted full text or confidential payloads.
- Escalate to the full counterpart when the decision is consequential, disputed, high-risk, multi-authority, route-complex or difficult to reconstruct.

Field semantics and controlled values are defined in `schemas/CSV_DATA_DICTIONARIES/TEMPLATE_FIELD_DICTIONARY.csv`.
