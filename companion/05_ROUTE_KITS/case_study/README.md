**Minimum planning evidence:** Case boundary, multiple evidence sources and a chain of evidence.  
**Immediate warning:** Organisation description replaces analytic argument.

## Hostile defence lens

**Question:** Why should one case support any implication beyond itself?  
**Bounded answer:** It does not support a population estimate. It supports a bounded analytic explanation whose transfer requires explicit comparison with another context.
