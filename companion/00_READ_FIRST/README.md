# Read first

This is Digital Companion v1.2.0 for *Student’s Guide to Research Projects, Theses and Dissertations: From Topic Selection to Evidence, Implementation, Writing and Defence* by Antonio Clim and Martino Aldrigo. Antonio Clim is the repository creator and curator.

The companion supplies editable, versioned records for the evidence-to-defence chain: workbook, quick-start guidance, templates, route kits, synthetic worked examples, AI-use TRACE and disclosure records, institutional-source registers, submission and defence controls, schemas, figures and validators.

Formal Appendices A–E are absent from book v3.9.0. Their stable methodological principles are integrated in the book and their operational objects are represented by modules DC-A–DC-E.

Start with `../02_QUICK_START/README.md`. Use official current instructions for consequential decisions and record the release version and access date of every companion object used.
