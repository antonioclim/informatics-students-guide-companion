# MODEL — Algorithmic or simulation study

**Locked route meaning:** How does a method or system behave under declared conditions?  
**Minimum planning evidence:** Formal assumptions, scenarios, comparator and sensitivity analysis.  
**Immediate warning:** One convenient scenario presented as general behaviour.  
**Claim boundary:** One dataset, parameter setting or machine becomes universal superiority or model truth

Use `ROUTE_GATE_PLAN.csv` to see what evidence the common nine-gate chain requires for this route. Use `ROUTE_RECORD_SELECTION.csv` to select shared templates and `RISK_AND_BOUNDARY_REGISTER.csv` to preserve the principal failure signatures. The `worked_example` folder is synthetic and schema-aligned. It is a teaching object, not an empirical result or a substitute for an approved project protocol.

## Demonstration lens

Re-run one limiting case, one moderate-load comparison and one adverse near-saturation case, then show the sensitivity table and run manifest.

## Hostile defence lens

**Question:** Why should a synthetic simulation justify any operational decision?  
**Bounded answer:** It does not establish production behaviour. It identifies conditional differences under explicit assumptions and exposes which workload features require measurement before deployment.
