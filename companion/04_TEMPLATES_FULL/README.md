# Full templates

Use a full template when the minimum record cannot preserve a reviewable decision, evidence chain, authority boundary, uncertainty, rights position or return route. Completion is not measured by cell count. A full record passes only when a competent reviewer can reconstruct the decision and challenge it using the named evidence.

- Preserve the original template and work on a versioned copy.
- Mark genuinely inapplicable fields explicitly rather than leaving consequential ambiguity.
- Link records by stable identifiers instead of duplicating evidence.
- Preserve rejected candidates and superseded records when they explain the final decision.
- Keep sensitive evidence in the authorised project workspace and record only a safe locator or identifier here.

Field semantics and validation rules are defined in `schemas/CSV_DATA_DICTIONARIES/TEMPLATE_FIELD_DICTIONARY.csv`.
