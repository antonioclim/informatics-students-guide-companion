# Changelog

## 1.2.0

- Aligned the Digital Companion with book v3.9.0 and Figure Authority v4.3.
- Preserved the complete DC-A–DC-E operational architecture, including the submission-package manifest, current-session submission control and DC-E narrative.
- Released 18 figure sets in SVG, PNG, ODG and PPTX formats under CC BY 4.0.
- Released scripts and validation code under the MIT License.
- Added a file-class licence register and regenerated repository manifests and SHA-256 registers.
- Removed duplicated author-supplied ODG copies, generated Python bytecode and obsolete release-hold documents from the public payload while retaining source hashes and canonical byte-identity evidence.

## Historical pre-release states

Versions 1.2.0-rc.1 to 1.2.0 and the live 1.1.1-rc.3 repository state were unpublished engineering candidates. They are superseded by v1.2.0 and remain identifiable only in explicit provenance and supersession records.
