# Native editability quality assurance

This directory records the object-level editability checks for the 18 ODG and 18 PPTX figure derivatives associated with **The Informatics Student’s Guide to Research Projects, Theses and Dissertations**.

The checks include native object counts, text round-trip tests, ODG text and fill-colour edit persistence, consolidated document counts, absence of embedded picture objects and visual comparison with the canonical SVG sources.

The SVG files in `../01_SVG_AUTHORITATIVE/` remain canonical for the book. ODG and PPTX files are editable derivatives. Any accepted visual change must be reconciled across the canonical SVG and the derivative formats before release.
