# PREDICT — Predictive or machine-learning study

**Locked route meaning:** How well does a model predict under a locked validation protocol?  
**Minimum planning evidence:** Provenance, split logic, baseline, metrics and error analysis.  
**Immediate warning:** Leakage or aggregate score hides failure.  
**Claim boundary:** Best metric becomes universal superiority, fairness or deployment value

Use `ROUTE_GATE_PLAN.csv` to see what evidence the common nine-gate chain requires for this route. Use `ROUTE_RECORD_SELECTION.csv` to select shared templates and `RISK_AND_BOUNDARY_REGISTER.csv` to preserve the principal failure signatures. The `worked_example` folder is synthetic and schema-aligned. It is a teaching object, not an empirical result or a substitute for an approved project protocol.

## Demonstration lens

Load the frozen held-out set, compare the keyword and linear baselines, inspect calibration and retrieve three adverse errors without live retraining.

## Hostile defence lens

**Question:** Why is the better aggregate score not sufficient for deployment?  
**Bounded answer:** Because the synthetic corpus, class-specific calibration and unresolved ambiguous errors bound the result. The study supports a comparative finding, not production automation.
